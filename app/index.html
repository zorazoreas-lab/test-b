Mod ujian sebenar, bukan sambungan platform: Audit menggunakan maklumat produk yang anda masukkan. Mod semak URL awam terhad ditambah; tiada akses akaun Shopee, TikTok atau Google; tiada ranking rasmi, jualan automatik atau jaminan kedudukan #1. Semua skor ialah heuristik dalaman.

Semak URL sebenar

Masukkan link awam Shopee, TikTok, TikTok Shop atau domain website yang anda benarkan untuk percubaan. Pemeriksaan metadata awam sahaja; sistem tidak menaikkan ranking, membuat klik atau mengubah produk.

Had URL audit

Kebanyakan listing Shopee/TikTok menggunakan kandungan dinamik, login atau sekatan anti-bot. Jika metadata tidak boleh diakses, sistem akan memberitahu sebab dan anda boleh terus melakukan audit manual. Domain website milik sendiri boleh ditambah dalam tetapan server.

Fungsi yang betul-betul ada

✓ Sahkan jenis URL dan domain
✓ Cuba membaca metadata awam yang dibenarkan
✓ Cadangan semakan tajuk dan penerangan
✓ Pindah metadata ditemui kepada audit produk manual
! Tiada ranking live atau Search Volume
! Tiada API Seller Centre atau penerbitan automatik
! Tiada login berbilang pelanggan dalam versi percubaan

Untuk keselamatan, deploy percubaan ini hanya di belakang kata laluan HTTPS. Maklumat audit disimpan pada browser, bukan database server.

Masukkan produk sebenar

Salin maklumat daripada listing yang anda miliki. Jangan masukkan kata laluan, OTP atau token API.

Hanya fakta yang boleh dibuktikan. Sistem tidak akan mencipta sijil halal, kelulusan, diskaun, bahan atau testimoni.

Import & eksport

Anda boleh memindahkan rekod antara peranti secara manual. Data kekal di browser ini. Tiada API akaun marketplace.

Pemulihan akan menggabungkan rekod dengan ID yang berbeza. Jangan import fail yang tidak dipercayai.

Maksimum 100 produk/fail. Fail CSV mesti menggunakan lajur yang sama dengan template; eksport Seller Centre mungkin perlu disesuaikan.

Cara ujian yang betul

  1. Pilih 1–5 produk milik sendiri di Shopee atau TikTok Shop.
  2. Salin tajuk, kata kunci, penerangan, harga, bilangan gambar dan fakta yang disahkan.
  3. Audit dalam SearchBoost, semak cadangan dan edit secara manual dalam Seller Centre.
  4. Rekod tarikh perubahan dan angka sebelum/selepas daripada analitik rasmi.
  5. Bandingkan tempoh setara. Jangan anggap perubahan berlaku hanya kerana tajuk diubah.

Had yang penting

URL audit hanya membaca metadata awam apabila dibenarkan; tiada live ranking, iklan automatik, akses API akaun, penjadualan audit produk atau penerbitan terus. Ini alat audit dan bukti konsep yang benar-benar berfungsi tanpa internet.

Privasi

Data disimpan dalam localStorage peranti. Data akan hilang apabila data pelayar dipadam. Jangan gunakan untuk data sensitif pelanggan. Penggunaan komersial memerlukan server selamat, login dan kawalan akses.
